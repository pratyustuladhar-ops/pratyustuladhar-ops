## 🙋‍♂️ About Me

I'm a **Software Developer** who designs, builds, tests and maintains real-world applications — from requirement to deployment. My work focuses on **web applications, POS & business management systems, and AI-integrated tools**, built mainly with **React, Laravel, JavaScript, Java and Python**.

- 💻 **Role:** Software Developer — full-stack web development
- 🔭 Currently building **POS platforms with React + Laravel** and AI projects like **JARVIS** and **AI-DOCS**
- 🌱 Continuously improving in **software design, APIs, databases and clean code**
- 🎸 Off the keyboard, I'm a **guitarist** — [@guitarist_prt](https://instagram.com/guitarist_prt)
- 💬 Ask me about **React, Laravel, JavaScript, Java, Python or building a POS system**
- ⚡ Fun fact: most of my favourite projects started as *"I wonder if I can build that…"*
